# Scripts

This folder contains all project scripts (*.ps1 and *.sh files) that were previously scattered throughout the repository.

## PowerShell Scripts (.ps1)

- **`check-redis-production.ps1`** - Check Redis status in production
- **`deploy-and-rebuild.ps1`** - Complete deployment script (build + deploy + rebuild)
- **`deploy-remote.ps1`** - Remote deployment to production server
- **`enable-redis-production.ps1`** - Enable Redis in production environment
- **`setup-ssh-key.ps1`** - Setup SSH key for deployment

## Shell Scripts (.sh)

- **`deploy-host-nginx.sh`** - Deploy nginx on host system
- **`deploy.sh`** - Deployment script (generated by deploy-remote.ps1)
- **`EMERGENCY_FIX_CERTBOT.sh`** - Emergency Certbot fixes
- **`entrypoint.sh`** - Nginx container entrypoint script
- **`fix-certbot-production.sh`** - Fix Certbot in production
- **`pre-commit.sh`** - Git pre-commit hook
- **`renew.sh`** - Certbot certificate renewal script
- **`setup-git-deployment.sh`** - Setup Git deployment
- **`setup-portainer-proxy.sh`** - Setup Portainer proxy configuration
- **`STOP_BROKEN_CERTBOT.sh`** - Stop broken Certbot processes
- **`test-import-curl.sh`** - Test import functionality with curl

## Usage

Most scripts are designed to be run from the project root directory. Check individual script headers for specific usage instructions.

### Main Deployment Script
```powershell
.\scripts\deploy-and-rebuild.ps1
```

### Remote Deployment
```powershell
.\scripts\deploy-remote.ps1
```
